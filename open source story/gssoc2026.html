01 THE BEGINNING

Why I chose to contribute.

Open source is not just about writing code. It is about becoming part of something larger.

Before GSSoC, most of my development experience was centered around building independently. Contributing to open source introduced a different way of working — understanding an existing repository, reading issues, adapting to established codebases and collaborating with people I had never worked with before.

The goal was not simply to make more commits. It was to learn how software is actually improved when multiple contributors work together.

THE SHIFT From building alone to building with a community.

08 LESSONS

The habits I am taking forward.

The biggest outcome was not a number on a leaderboard. It was a better way of approaching software.

I learned to read before coding, understand the context of a problem before proposing a solution and treat feedback as a tool for improvement.

Most importantly, open source changed the way I think about software development: good code does not only need to work — it needs to fit into the system around it.

TAKEAWAY Write code that works. Contribute code that belongs.
